# Sky Flapper

A small flappy-style browser game written in plain HTML, CSS and JavaScript (no build step, no dependencies).

## Play

**▶ Play online: https://fabbeboss.github.io/flappy-game/**

Or open `index.html` locally in a browser.

**Controls:** Space / ↑ / click / tap to flap · P to pause

## Files

- `index.html` – page and canvas
- `style.css` – layout
- `game.js` – game loop, physics, drawing and input
